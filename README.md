# Método de Monte Carlo em Java

Implementação de exercícios utilizando o **Método de Monte Carlo**, desenvolvidos na disciplina de Projeto e Análise de Algoritmos do curso de Bacharelado em Ciência da Computação do Instituto Federal do Ceará (IFCE) – Campus Iguatu.

## Sobre o projeto

O objetivo deste projeto é aplicar o método de Monte Carlo na resolução de problemas que envolvem estimativas probabilísticas e aproximações numéricas, utilizando a linguagem Java.

## Exercícios propostos

### Questão 1 – Simulação de lucro de uma sorveteria

Simulação do lucro mensal esperado de uma sorveteria, considerando três cenários de demanda influenciados pelas condições climáticas: alta, média e baixa demanda.

Cada cenário possui uma probabilidade de ocorrência e um lucro médio diário específico. O objetivo é simular um período de 30 dias e estimar o lucro mensal esperado.

### Questão 2 – Simulação de lucro de um site de notícias

Simulação do lucro mensal esperado de um site de notícias, considerando três categorias de visitantes: muito engajados, medianamente engajados e pouco engajados.

Cada categoria possui uma probabilidade de ocorrência, uma quantidade média de cliques por dia e um valor recebido por clique. O programa realiza uma simulação de 30 dias e compara o lucro obtido com o valor esperado matematicamente.

### Questão 3 – Estimativa de área por Monte Carlo

Utilização do método de Monte Carlo para estimar a área sob o gráfico da função \(f(x) = x^2\), no intervalo [0, 1].

O algoritmo utiliza pontos aleatórios para estimar a área e compara o resultado obtido com o valor calculado por meio da integral definida.

## Tecnologias utilizadas

- Java
- `java.util.Random`
- Programação estruturada
